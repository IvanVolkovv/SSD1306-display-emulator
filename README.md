### Общее описание:
Эта простая программа может использоваться чтобы упростить создание графических сцен для монохромных экранов, построенных на контроллерах: SSD1306, ST7567A. 
Программа эмулирует монохромный экран, на котором можно отобразить созданную вами графическую сцену, тем самым не требуется каждый раз 
запускать код в "железе". Такой подход позволяет отладить дизайн графичекой сцены перед тем, как использовать конечный алгоритм построения
изображения. 

### Как пользоваться программой?
Последовательность действий, которая раскрывает основную суть применения программы показана на рисунке ниже:
<p align="center">
  <img src="https://github.com/user-attachments/assets/e0739929-0c9c-46d3-95fc-6480b93d1d10">
</p>

1. Вы отлаживаете часть кода, которая генерирует графическую сцену. Графическая сцена представляет собой однобайтовый массив данных, в котором каждый байт управляет соответствующим сегментом дисплея, состоящего из 8-ми пикселей;
2. В итоге, ваша графичекая сцена располагается в однобайтовом массиве данных (например, массив типа uchar или uint8_t);
3. Вы сохраняете массив в файл формата - .txt;
4. Загружаете файл.txt в программу и наблюдаете результат.

Для примера, в директории -> Example_for_creating_image находится простая программа, которая генерирует графическую сцену и сохраняет её в файл.txt, который Вы можете загрузить и просмотреть результат.

1. Кнопка - Open file. Первое действие которое необходимо выполнить - это зарузить файл.txt, для этого нужно нажать на кнопку, после чего откроется диалоговое окно выбора файла. После того как нужный файл будет выбран, изображение тут же будет построено на графической сцене - 5.
2. Кнопка - Update file. Отладка графической сцены может содержать много интераций для исправления мелких деталей, поэтому каждый раз после внесения изменений искать и открывать файл может быть нудно и занимать лишнее время. Поэтому, если Вы пересохранили файл.txt после того как открыли этот файл в программе, для нового построения изображения Вы можете просто нажать эту кнопку. Идея в том, что при первом открытии файла, путь к нему сохраняется и кнопка "Update file" просто заново загружает и строит изображение, используя ранее сохраненный путь к файлу.
3. Кнопка - Save Display. Используется для сохранения изображения графической сцены в виде картинки формата PNG.
4. Пункты меню которые управляют размером дисплея, пикселей и т.д.
5. Графическая сцена.
